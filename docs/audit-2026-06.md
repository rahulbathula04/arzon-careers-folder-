## Phase 1 - Universal Typography (this PR)

New tokens added to `src/styles.css`:

- Fluid type scale via `clamp()`:
  `--fs-display`, `--fs-h1`..`--fs-h4`, `--fs-body-lg`, `--fs-body`, `--fs-body-sm`, `--fs-caption`, `--fs-overline`.
- Line-height tokens: `--lh-tight | snug | normal | relaxed`.
- Tracking tokens: `--tracking-tight | normal | wide`.
- Spacing rhythm tokens: `--space-section-y`, `--space-block-y`, `--space-stack-sm|md|lg`.
- Tailwind utilities exposed via `@theme inline`:
  `text-display`, `text-h1`..`text-h4`, `text-body`, `text-body-sm`, `text-caption`, `text-overline`.
- `.prose-arzon` long-form utility with `max-w-[65ch]`, `text-pretty`, `text-balance` on headings, tabular-nums for stats.

Replaces ad-hoc chains like `text-2xl md:text-4xl lg:text-6xl` with single-class semantic sizing.

### Migration workflow

1. Pick one surface from the Phase 3 funnel list.
2. Replace ad-hoc `text-[Npx]` / `text-Nxl` with semantic utilities - never raise pixel sizes by more than ½ step.
3. Visually verify at 360 / 768 / 1280 (Playwright).
4. Run `node scripts/check-typography-tokens.mjs` - if green and the file's count went down, run `--update-baseline` and commit the new baseline alongside the file changes.
5. Same loop for heading hierarchy when a route is migrated.

## 2026-06-17 - Phase 3 universal migration (bulk)

Single-pass migration of arbitrary `text-[Npx]` Tailwind classes across the entire `src/` tree (excluding `src/components/ui` shadcn primitives) to semantic typography utilities defined in `src/styles.css`.

Mapping applied (px → utility):

- ≤11.5 → `text-micro`
- ≤12.9 → `text-meta`
- ≤13.9 → `text-caption`
- ≤15.9 → `text-body-sm`
- ≤17.5 → `text-body`
- ≤19.5 → `text-body-lg`
- ≤22 → `text-h4`, ≤28 → `text-h3`, ≤38 → `text-h2`, ≤52 → `text-h1`, else `text-display`

Result:

- 192 files touched, 1281 replacements
- Ratchet baseline: 193 files / 1340 offenders → **37 files / 59 offenders** (-95.6%)
- Remaining 59 = 51 decorative `text-Nxl` (emoji/numerals) + 7 `leading-[…]` + 1 stray `text-[…rem]`
- All three guardrails (`check-typography-tokens`, `check-heading-hierarchy`, `check-font-defaults`) wired into `.github/workflows/typography-gates.yml` - CI fails on any per-file regression

Funnel surfaces covered in this pass: Home, Catalog, Career Engine, Apply/Enrol, Industry, Recruiter/TPO, all 25 track course pages, Admin. Heading hierarchy: 12 pre-existing findings (8 multiple-h1, 4 no-h1) tracked in `scripts/.heading-baseline.json` for follow-up - none introduced by this pass.
