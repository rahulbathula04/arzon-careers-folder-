# Arzon Organic Growth System: SEO + GEO 90-Day Plan

_Last updated: 2026-09-28_

## Objective

Build a policy-compliant organic acquisition system capable of targeting **100,000 qualified leads in 90 days**.

100,000 is a business target, not a guaranteed SEO outcome. The operating model is:

```
Search + AI/GEO + local discovery + jobs intelligence + research + tools
                                ↓
                         organic visitors
                                ↓
                         useful free asset
                                ↓
                        Career Engine / tool
                                ↓
                              lead
                                ↓
                     qualification + counsellor
```

The primary acquisition identity is **healthcare career intelligence**, not course promotion.

## Page model

Every indexable high-intent page should answer:

1. What is this career/role?
2. Who is eligible?
3. What work is performed?
4. Which skills are required?
5. Which tools are used?
6. What employers hire for it?
7. What salary information is available?
8. What does the career path look like?
9. What current job evidence supports the page?
10. What should the reader do next?

Use original analysis and first-party data wherever possible.

## Lead model

The site should not force every visitor directly to a programme.

### Informational intent

```
Guide → free tool → report → lead
```

### Job intent

```
Job intelligence → eligibility/skill check → Career Engine → lead
```

### Degree intent

```
Degree pathway → role selection → Career Engine → lead
```

### Programme intent

```
Programme → evidence → cohort → enrolment/counsellor
```

## Lead-quality model

Capture only information needed for a legitimate career-assistance purpose.

Recommended dimensions:

- degree
- graduation stage
- target role
- preferred city
- experience level
- assessment completion
- programme interest
- contact consent

Do not manufacture urgency, employment guarantees, placement guarantees, salary guarantees, employer endorsements, reviews, or job availability.

## GEO strategy

For AI-generated search experiences, pages should contain concise, independently understandable answers followed by supporting evidence.

Recommended structure:

```
Direct answer
Key facts
Eligibility
Responsibilities
Skills
Tools
Employers
Salary context
Career path
Current evidence
Methodology
Related questions
Related roles
Career Engine
```

The goal is to make Arzon's research and career explanations useful source material. There is no special Google ranking switch for an `llms.txt` file; Google has explicitly clarified that it is not required for Google Search. 

## Structured data rules

Use structured data only when it describes visible, accurate page content.

Priority types:

- Organization
- BreadcrumbList
- Course
- Article/BlogPosting
- Dataset for qualifying research datasets
- JobPosting only on individual, real job detail pages
- LocalBusiness where the real-world business qualifies
- ProfilePage where appropriate

Do not add fake ratings, fake reviews, fake jobs, or unsupported employer relationships.

Google's documentation says structured data helps it understand page content and recommends validating markup and testing representative URLs before scaling deployment.

## Sitemap rules

- Canonical host: `https://arzoncareers.in`
- No synthetic `lastmod`
- Include canonical indexable URLs
- Exclude noindex/private/transactional routes
- Add genuine last modification dates only when reliable
- Keep sitemap parity checks in CI

## Compliance and search-quality guardrails

Never use:

- purchased/spam backlinks
- fake reviews
- fake business locations
- fake jobs
- scraped job pages with no original value
- mass AI pages with minimal value
- doorway pages
- keyword stuffing
- hidden text
- fake testimonials
- fabricated employer relationships
- misleading placement or salary claims

Google's current spam guidance explicitly covers scaled content abuse, including large volumes of low-value AI-generated or otherwise non-original pages.

The system is ready when:

- every major search intent maps to one canonical URL
- every important page has a clear next action
- every lead has source + intent attribution
- every programmatic page has a data-backed reason to exist
- research pages expose methodology
- structured data matches visible content
- stale job/cohort claims cannot remain indexable
- noindex routes cannot enter the sitemap
- organic traffic and lead conversion can be reported by page and intent
- content can be expanded without creating thin-page debt
